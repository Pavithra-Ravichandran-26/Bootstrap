Semantic Tags Found

Tag Usage
<header> Contains website logo and title.
<nav> Contains navigation links like Home, World, Business, Sports.
<main> Contains the primary news content.
<section> Groups news into categories such as World, Business, Technology, and Sports.
<article> Represents each individual news story.
<aside> Displays related news, trending stories, or advertisements.
<footer> Contains copyright and policy links.

Conclusion

CNN.com and BBC.com both use semantic HTML elements to organize their webpages. Navigation menus are placed inside <nav>, news stories inside <article>, categories inside <section>, related content inside <aside>, and copyright information inside <footer>. This structure improves SEO, accessibility, and code readability.
